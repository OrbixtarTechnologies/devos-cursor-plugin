# Project Memory Schema

- project
- purpose
- stack
- environments
- non-negotiable constraints

## `.devos/architecture.md`
- system map
- components
- interfaces
- data stores
- external integrations

- hotspots

Each decision: date, status, decision, context, alternatives, rationale, consequences.

## `.devos/worklog.md`
Each entry: date, task, outcome, verification, open risks.
