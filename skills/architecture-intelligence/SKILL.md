---
name: architecture-intelligence
description: Map repository architecture from file evidence, including boundaries, data flow, and change impact.
---

Build a lightweight architecture model from repository evidence: apps, packages, services, data stores, integrations, entry points, and dependency edges. Identify ownership boundaries and change hotspots.

For meaningful changes, state affected components, data flow, failure modes, and migration/rollback considerations. Prefer evidence from actual files over inferred conventions.
