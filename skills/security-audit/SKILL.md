# Security Audit

Focus on attack surface, trust boundaries, authentication, authorization, input validation, secrets, dependency risk, file/system access, SSRF, injection, XSS, CSRF, unsafe deserialization, and sensitive-data exposure.

For each finding: asset → attacker capability → path → evidence → impact → remediation → residual risk.

Never fabricate CVEs, exploitability, or compliance status.
