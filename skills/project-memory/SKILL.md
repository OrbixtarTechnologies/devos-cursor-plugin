description: Maintain durable DevOS project memory in .devos/ without storing secrets.
---

Maintain a `.devos/` directory when the project benefits from durable AI context.

Recommended files:
- `project.md` — goals, stack, constraints
- `architecture.md` — system map and boundaries
- `decisions.md` — ADR-style decisions
- `worklog.md` — dated execution log
- `tasks/` — active execution plans

Never write secrets or credentials. Keep entries short, factual, and durable.
