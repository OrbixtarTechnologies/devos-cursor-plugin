# Implementation

## Workflow
1. Confirm plan and inspect current files.
2. Make the smallest coherent change.
3. Re-read modified code in context.
4. Run the narrowest relevant verification immediately.
5. Expand verification for integration boundaries.
6. Review the diff and summarize exactly what changed and what remains.

## Quality Bar
No dead code, debug leftovers, accidental formatting churn, invented APIs, or unverified claims.
