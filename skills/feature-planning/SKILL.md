# Feature Planning

## Workflow
1. Restate the requested outcome in behavioral terms.
2. Inspect the current implementation before proposing edits.
3. Identify affected layers, contracts, data flows, and dependencies.
4. Define acceptance criteria and failure cases.
5. Produce a minimal ordered plan with file-level intent.
6. Define verification commands and expected evidence.

## Output
Problem → constraints → design → file plan → risks → acceptance criteria → verification.
